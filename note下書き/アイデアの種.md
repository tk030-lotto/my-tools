# note 記事ネタ・アイデアの種

## 💡 ストック一覧

### 📌 2026-08-28: note記事から公開ツールカタログを全自動生成！API連携とURL自動抽出で同期スクリプトを堅牢化した話
- **カテゴリ**: AI開発 / 開発ノウハウ / 運用自動化
- **背景・動機**:
  - noteで公開した自作ツールの紹介記事を、Web上の公開ツール一覧サイト（カタログ）へ手動登録する手間をゼロにしたい。
  - バッチ実行時に発生したWindowsコンソールの文字化け（CP932 vs UTF-8）や、note APIのフィールド仕様の違い（`publish_at`）、本文内リンク抽出の課題を解決。
- **主なポイント・技術的インサイト**:
  1. **Windowsバッチの文字化け撲滅**: `chcp 65001 > nul` の指定による完全UTF-8化。
  2. **note APIの2段階連携**: マガジン一覧API（`api/v1/magazines/...`）で全体を走査し、新規候補のみ単体詳細API（`api/v3/notes/{key}`）で本文を取得する効率的アーキテクチャ。
  3. **本文からのURL正規表現抽出**: 記事中に埋め込まれた GitHub リポジトリ（`github.com/...`）や GitHub Pages（`*.github.io/...`）のURLを自動抽出し、手動入力ゼロでカタログJSON（`tools.json`）を構成。
  4. **非破壊的マージ更新**: ユーザーが手動でリッチに追記した「なぜ作ったか（Why）」「特徴（Features）」を上書き破壊せず、未設定のURLや公開日のみを安全に補完するデータ更新ロジック。
- **読者への価値**:
  - 「個人開発ツールが増えてきたが、ポートフォリオやカタログの更新が面倒」という開発者が、記事を書くだけで自動的にサイトに反映される仕組みをそのまま真似できる実践ノウハウ。
